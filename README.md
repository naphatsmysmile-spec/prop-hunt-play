# Prop Hunt — ลิงก์เข้าเกม

หน้านี้คือ **ลิงก์ถาวร** สำหรับเข้าเกม Prop Hunt

ตัวเกมรันบนเครื่องของเจ้าของห้องผ่าน Cloudflare quick tunnel ซึ่งที่อยู่จะเปลี่ยน
ทุกครั้งที่เปิดใหม่ หน้านี้เลยทำหน้าที่อ่านที่อยู่ปัจจุบันจาก `server.json`
แล้วพาไปให้เอง — เพื่อนจำลิงก์เดียวพอ

## เวลาที่อยู่เซิร์ฟเวอร์เปลี่ยน

แก้ `url` ใน `server.json` แล้ว push ลิงก์เดิมจะใช้ได้ต่อทันที

```json
{ "url": "https://xxxx.trycloudflare.com" }
```

ซอร์สโค้ดเกมอยู่คนละ repo (private)
